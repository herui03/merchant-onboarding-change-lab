Reset and restart

The database persists across restarts in instance/merchant_onboarding_lab.db. To start the demo again, stop the server and run:

./launch_demo.command --reset

Reset first copies the current database into instance/backups/, then creates a fresh synthetic seed. There is no reset button in the web UI.
